# AC Bridge 설치 안내

Samsung 시스템 에어컨을 **SmartThings**에서 제어할 수 있게 해주는 브릿지 앱입니다.
안드로이드 기기에서 상주 서버로 동작하며, SmartThings와 에어컨(EW11) 사이를 중계합니다.

```
Samsung 시스템 에어컨
      ↕ RS485
   EW11 (WiFi 브릿지)
      ↕ TCP (같은 WiFi)
  📱 AC Bridge 앱   ← 이 앱을 설치합니다
      ↕ TCP
   SmartThings
```

---

## ✅ 준비물

- **안드로이드 기기** (Android 7.0 / API 24 이상) — 항상 켜둘 수 있는 기기 권장 (예: 안 쓰는 폰/태블릿을 충전기에 연결)
- **EW11 WiFi 브릿지**가 에어컨에 연결되어 있고, 안드로이드 기기와 **같은 WiFi**에 있을 것
- **`app-release.apk`** 파일 (배포받은 설치 파일)

---

## 📥 설치 방법

### 1. APK 파일을 기기로 옮기기
카카오톡, 이메일, Google Drive, USB 등 편한 방법으로 `app-release.apk`를 안드로이드 기기에 복사합니다.

### 2. "출처를 알 수 없는 앱" 설치 허용
Play 스토어를 거치지 않는 앱이라 최초 1회 허용이 필요합니다.

- 파일 관리자에서 `app-release.apk`를 탭 → 설치 시도
- "이 출처의 앱 설치 차단됨" 안내가 뜨면 **설정 → 허용**을 켜줍니다
  - (경로 예시: `설정 → 앱 → 특별한 접근 → 알 수 없는 앱 설치`)

### 3. 설치
다시 APK를 탭하여 **설치** → 완료되면 **열기**.

---

## ⚙️ 최초 설정

앱을 처음 열면 아래 순서로 설정합니다.

1. **Settings(설정)** 버튼 → EW11 정보 입력
   - **EW11 Host**: EW11의 IP 주소 (예: `192.168.0.38`)
   - **EW11 Port**: 기본 `8899`
   - **Bridge Server Port**: SmartThings가 접속할 포트, 기본 `8888` (그대로 두면 됩니다)
2. 뒤로 나와서 **Start Service(서비스 시작)** 버튼 탭
3. 화면에 표시되는 **연결 주소**를 확인합니다
   ```
   Bridge Address (for SmartThings)
   192.168.0.42:8888
   ```
   > 이 주소(`IP:포트`)를 SmartThings 연동 시 입력합니다. 길게 눌러 복사할 수 있습니다.

---

## 🔗 SmartThings 연결

SmartThings Edge Driver 설정에서, 위에서 확인한 **`기기IP:포트`** 주소를 입력하면 연결됩니다.

> ⚠️ 안드로이드 기기의 IP가 바뀌면(WiFi 재접속 등) 재연결이 필요할 수 있습니다.
> 공유기에서 이 기기에 **고정 IP(DHCP 예약)** 를 지정해 두면 안정적입니다.

---

## 🔒 권한 안내

- **알림 권한**: 서비스가 백그라운드에서 계속 실행 중임을 표시하기 위해 필요합니다 (Android 13+).
- 별도의 위치·연락처 등 민감 권한은 요구하지 않습니다. 네트워크 접근만 사용합니다.

---

## 💡 사용 팁

- **항상 켜두기**: 이 앱이 꺼지면 SmartThings에서 에어컨을 제어할 수 없습니다. 충전기에 연결된 고정 기기에 설치하세요.
- **배터리 최적화 제외**: `설정 → 배터리 → 배터리 최적화`에서 AC Bridge를 **최적화 안 함**으로 지정하면, 시스템이 서비스를 임의로 종료하는 것을 막을 수 있습니다.
- **재부팅 후**: 기기를 재시작하면 앱을 다시 열어 **Start Service**를 눌러야 합니다.

---

## 🛠️ 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 연결 주소가 "Not connected to Wi-Fi"로 표시됨 | 기기가 WiFi에 연결되어 있는지 확인 |
| SmartThings에서 연결 실패 | 안드로이드 기기와 SmartThings 허브가 **같은 네트워크**인지, 주소(IP:포트)가 정확한지 확인 |
| 에어컨이 반응 없음 | EW11 Host/Port가 맞는지, EW11이 켜져 있고 같은 WiFi인지 확인 |
| 잠시 후 서비스가 꺼짐 | 배터리 최적화 제외 설정(위 팁 참고) |
| 앱 업데이트 설치가 안 됨 | 같은 서명의 새 APK인지 확인 (다른 키로 서명된 APK는 기존 앱 삭제 후 설치 필요) |
